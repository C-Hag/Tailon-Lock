# Full Burn: the road to "Arp sound DMX10"

The versions of the main theme that came before DMX10, all on our own drum
machine (`../../lib/h2h-drum`), plus the opening film with the final score.
The theme itself is `../fullburn-dmx10.mp3`.

| file | what changed |
|---|---|
| `fullburn-dmx6.mp3` | the arrangement on our own synthesised drum kit, h2h-drum |
| `fullburn-dmx7.mp3` | short choked cymbals in a few places, a solo spot on the lead |
| `fullburn-dmx8-a.mp3`, `-b`, `-c` | three h2h-solo takes: solos that elaborate the song's own melody |
| `fullburn-dmx9.mp3` | the amped SID guitars, a smoother way into the drums, the solo on riff 2, the guitar takes the bell section |
| `tailonlock-intro.mp4` | the opening film (66 s), scored to DMX10, with the hand-off into the menu theme (14 MB) |

The game itself plays DMX10 (`assets/music/fullburn.wav`) and the film cut
(`assets/music/fullburn-intro.wav`).
