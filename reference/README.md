# Browser version (reference)

The original single-file HTML5 versions, kept here so the C port can be
checked against them line by line. The plan's module map and the comments in
`src/` refer to line numbers in `ace4combat.html`.

- `ace4combat.html`: the game.
- `carrier-dawn.html`: the music listening page.

Open either file in a browser to compare behaviour. They are not built or
shipped.
